# study-plan

## My Study Plan

### Daily (Mon-Fri)
- 30 min: Review notes from the previous session
- 60 min: Learn one focused topic
- 30 min: Practice with exercises or examples

### Weekly
- Monday: Set learning goals for the week
- Tuesday-Thursday: Deep study and practice
- Friday: Build a small project or summary
- Weekend: Review progress and plan next week

### Monthly Checkpoint
- Revisit completed topics
- Identify weak areas and adjust priorities
- Update goals based on progress
